## Future 360-degree enhancement

These are flat photographs, not 360-degree assets. A later true scroll-controlled upgrade requires licensed stabilized orbital footage, a consistent full-orbit image sequence, or an accurate textured 3D model of the Kaaba and its surroundings, with commercial web distribution rights. Supply source files and license evidence. Keep the existing photograph as the mobile, reduced-motion, slow-connection and WebGL-unavailable fallback. A fixed viewpoint equirectangular panorama allows looking around but is not an orbital camera view.

Runtime aliases: `kaaba.webp` is the same optimized image as `kaaba-hero.webp`; `haram.webp` is the same optimized image as `kaaba-detail.webp`.
